## 一、这套文档的设计原则

1. **文档是唯一事实来源，不是 AI 的记忆。** 任何时候我只需读对应文件就能恢复全部上下文，不需要你重复讲。
2. **一个文件只干一件事。** 计划、记录、复盘、错题、知识点分开，互不污染。
3. **文件名自带坐标。** 看到 `W03-D2` 就知道是第 3 周第 2 天，看到 `005` 就知道是第 5 题。
4. **所有结论可回溯。** 每道错题都保留"当时写错的代码"，不只留正确答案——**错误的形状比正确的形状更有诊断价值**。
5. **不压缩细节。** 项目文档宁可长，不能缺。

## 三、每天怎么用（4 步）

| 步骤 | 时间 | 做什么 | 涉及文件 |
|---|---|---|---|
| 1 | 08:20 | 收到我的提醒，看当天任务 | 收到的消息 / `第NN周-任务卡` |
| 2 | 08:30–11:30 | 照任务卡做：读题→纸上推演→编码→自测→复盘 | `第NN周-任务卡`、`示范题-001`、`模板库` |
| 3 | 11:30 | 发我 **4 行汇报**（格式见下） | 对话 |
| 4 | 11:35 | 我更新：每日记录、复盘、错题本、进度总览 | `02-每日记录`、`03-单题复盘`、`04-错题本`、`进度总览` |

### 4 行汇报格式

```
W01-D2 完成（11/17，投入 150 分钟）
① 26 删除有序数组中的重复项：独立做出，卡在原地修改的含义
② 27 移除元素：看了提示，用 remove 导致下标错位
③ 问题：为什么 nums.remove() 在循环里会漏删
④ 裸写重写：1/2 通过
```

- ①② 必须标清 **独立 / 看了提示 / 抄了题解**。这个标记决定错题优先级，含糊了整套机制失效。
- ③ 有几个问题写几个。
- ④ 裸写又错的，才是真没学会的。

### 代码优化提问格式

```
【题号】242
【我的解法】（贴代码）
【我的复杂度判断】时间 O(n log n)，空间 O(n)
【想问】有没有更快的？边界有没有问题？
```

我的回复固定按 **正确性 → 真实复杂度 → 可读性 → 更优解** 顺序，不会只说"这样更好"。

## 七、三条铁律（写在最前面，因为最容易破）

1. **裸写不通过 = 没学会。** 不看笔记能写出来并过全部用例，才算这道题完成。
2. **错题必须保留错误代码。** 只记正确答案的错题本没有诊断价值。
3. **按完成度推进，不按日期推进。** 某周少来一天，就整周顺延，不压缩内容。

# 命名规范

> 目的：只看文件名就知道是哪一周、哪一天、哪一题、什么类型，能直接按名字搜索定位。
> 修改任何文件命名前先看这一页。

---

## 一、文件夹编号

| 编号 | 名称 | 放什么 | 增长方式 |
|---|---|---|---|
| `00` | 导航 | 总目录、命名规范 | 固定 2 个 |
| `01` | 计划 | 总计划、进度表、每周任务卡 | 每周 +1 个任务卡 |
| `02` | 每日记录 | 每天一条执行记录 | 每天 +1 个 |
| `03` | 单题复盘 | 每题四行复盘 | 每周 +1 个 |
| `04` | 错题本 | 错题索引、高频攻坚、明细 | 每周 +1 个明细 |
| `05` | 知识点与模板 | 知识点讲解、代码骨架、示范题 | 按需 |
| `06` | 题解代码 | 自己写通的 AC 代码，一题一文件 | 每题 +1 个 |
| `07` | 归档 | 旧版本，只读 | 按需 |

编号前缀的作用：**在文件管理器里永远按 导航 → 计划 → 记录 → 复盘 → 错题 → 知识 → 代码 的顺序排列**，不会被字母序打乱。

## 二、文件名格式

### 1. 每周任务卡 → `01-计划\`

```
第NN周-D1至D6-任务卡.md
```
示例：`第01周-D1至D6-任务卡.md`、`第03周-D1至D6-任务卡.md`

### 2. 每日记录 → `02-每日记录\`

```
WNN-DX-YYYY-MM-DD-周X.md
```
示例：`W01-D1-2026-11-16-周一.md`

- `WNN` 周次补零（W01…W14）
- `DX` 天次不补零（D1…D6）
- 日期用 `YYYY-MM-DD`，避免 `11-16` 这种跨年歧义

### 3. 单题复盘 → `03-单题复盘\`

```
WNN-复盘.md
```
示例：`W01-复盘.md`

### 4. 错题本 → `04-错题本\`

```
错题总表.md                    ← 固定名，全局唯一索引
高频复发-重点攻坚.md            ← 固定名
明细-WNN.md                    ← 每周一个
```
示例：`明细-W01.md`

### 5. 知识点 → `05-知识点与模板\`

```
知识点-WNN-主题.md
```
示例：`知识点-W01-Python语法基础.md`、`知识点-W06-链表双指针.md`

### 6. 示范题 → `05-知识点与模板\`

```
示范题-NNN-题目名.md
```
题号 **三位补零**，示例：`示范题-001-两数之和.md`、`示范题-015-三数之和.md`

补零的原因：这样 `001 < 015 < 100` 按名字排序就是按题号排序，不会出现 `100` 排在 `15` 前面。

### 7. 题解代码 → `06-题解代码\`

```
NNN-题目名.py
```
题号 **三位补零**，示例：`001-两数之和.py`、`015-三数之和.py`、`146-LRU缓存.py`

- 一个文件只放一道题
- 文件头固定写三行注释：题号标题、日期与坐标、复杂度
- 同一题有多个解法时，用 `-v1` `-v2` 后缀区分（`001-两数之和-v1.py` 暴力解、`-v2` 哈希解）

### 8. 归档 → `07-归档\`

```
旧版-YYYY-MM-DD\原文件名.md
```

## 三、坐标速查（怎么用名字找东西）

| 我想找 | 搜索关键字 | 命中文件 |
|---|---|---|
| 第 3 周全部内容 | `W03` | 复盘、明细、5 个每日记录 |
| 第 3 周第 2 天 | `W03-D2` | 每日记录 + 任务卡里那一节 |
| 第 15 题的所有痕迹 | `015` | 示范题（如有）、复盘里的条目、错题明细 |
| 两数之和 | `001` 或 `两数之和` | `示范题-001-两数之和.md` |
| 链表相关知识点 | `链表` | 知识点文件 + 任务卡 + 复盘 |
| 我这周错了几题 | `明细-W03` | 第 3 周错题明细 |

**推荐搜索方式**：在 VS Code 里按 `Ctrl+P` 输 `W03`，或在文件资源管理器搜索框输 `W03-D2`。

## 四、写文件时的固定要求

每个新建文档都必须有头部三行，格式固定：

```markdown
# 文档标题

> 用途：一句话说清这文件干什么
> 关联：W01-D2 ／ 题号 026、027
> 更新：2026-11-17
```

正文要求：
1. **结论先行**：先说这题/这知识点是什么，再展开。
2. **可回溯**：涉及错题必须保留当时的错误代码，不能只留正确答案。
3. **可执行**：写"怎么做"，不写"要注意"这种空话。
4. **带坐标**：提到某道题必须带题号，提到某天必须带 `WNN-DX`。

## 五、禁止事项

| 禁止 | 原因 |
|---|---|
| 文件名带空格 | 脚本处理和搜索都容易断 |
| 文件名带版本号（`v2`、`最终版`） | 版本靠日期和 git 管理，不靠文件名 |
| 用 `新建文档.md`、`未命名.md` | 无法定位 |
| 一个文件塞两类内容（如复盘 + 错题混写） | 违背"一个文件只干一件事" |
| 修改已有文件名而不更新本页 | 索引失效，等于毁掉定位能力 |

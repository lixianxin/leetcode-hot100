## D1 · 11/24 周二 · set 与 tuple、集合运算

**知识点**（约 25 min）：`set()` 无序不重复、`&` 交集 `|` 并集 `-` 差集、tuple 不可变、`enumerate` 的元组解包。

| 题 | 通关标准 | 自测用例 |
|---|---|---|
| **268 丢失的数字** | 不许用公式 `n(n+1)/2` 一行过——**用 set 差集写**（这正是 014 的教训：set 只回答"在不在"，不回答顺序；本题恰好在不在 | `[3,0,1]`→2、`[0,1]`→2、`[9,6,4,2,3,5,7,0,1]`→8、`[0]`→1 |
| **448 找到所有数组中消失的数字** | 返回**列表**；注意值域 1..n 与下标错位 1 | `[4,3,2,7,8,2,3,1]`→[5,6]、`[1,1]`→[2]、`[2,2]`→[1] |

**常见坑**：268 禁止只报公式解（第 3 周哈希周会重做，公式解到时是加分项）；448 用 set 时想清「应该是谁的差集」。

## D2 · 11/25 周三 · sorted 与切片进阶

**知识点**：`sorted(key=lambda)`、`a[::-1]` 反转、`a[start:stop:step]` 全家桶、`sorted` 不改原表 vs `sort` 原地。

| 题 | 通关标准 | 自测用例 |
|---|---|---|
| **88 合并两个有序数组** | **原地**写进 nums1（从后往前填，m、n 指针）——从前往后覆盖会丢数据，这是本题题眼 | `[1,2,3,0,0,0]`+[2,5,6]→[1,2,2,3,5,6]、`[1]`+[]→[1]、`[0]`+[1]→[1] |
| **977 有序数组的平方** | 有序数组平方后仍有序——**不许平方后 sort 一行过**，用双指针从两头收 | `[-4,-1,0,3,10]`→[0,1,3,4,10]、`[-7,-3]`→[9,49]、`[5]`→[25] |

**常见坑**：88 从后往前时 `n > 0` 和 `m > 0` 哪个条件先写完剩谁直接抄谁（剩下的是 nums2 前缀时才需要补）；977 两头比较取**绝对值大**的那端。

## D3 · 11/26 周四 · 列表推导式与字符串处理

**知识点**：推导式 `[f(x) for x in a if cond]`、双循环推导式、字符串不可变、`"".join` 要求元素全 str。

| 题 | 通关标准 | 自测用例 |
|---|---|---|
| **344 反转字符串** | **原地双指针**交换（这题用 for 强制步进，别再手写 while 步进） | 通用 |
| **125 验证回文串** | 只比字母数字、忽略大小写——先过滤再判断；不许建新串反转比较以外的高级解 | `"A man, a plan..."`→true、`"race a car"`→false、`" "`→true（**空串算回文**）、`"0P"`→false（数字字符参与判断） |

**常见坑**：125 的 `char.isalnum()` 忘了数字也合法 → `"0P"` 会错；过滤时别用 `str.strip()`（只去两端）。

## D4 · 11/27 周五 · Counter / defaultdict / 手写计数

**知识点**：`collections.Counter`（`most_common`、相等比较）、`defaultdict(int/list)`、dict 遍历 `items()`。

| 题 | 通关标准 | 自测用例 |
|---|---|---|
| **383 赎金信** | 手写计数版必写；`Counter(ransom) & Counter(magazine)` 的**多重集合交集**写法当版②了解 | `"a"`+`"b"`→false、`"aa"`+`"aab"`→true（**数量也要够**）、`""`+`""`→true |
| **387 字符串中的第一个唯一字符** | 两遍遍历：先计数再找第一个 count==1 的**下标**；返回 -1 表示没有 | `"leetcode"`→0、`"loveleetcode"`→2、`"aabb"`→-1 |

**常见坑**：387 别用 `s.index(s[i])` 的写法（又 O(n²) 又绕）；383 注意是「 magazine 里数量够不够」不是「字符在不在」。

## D5 · 11/28 周六 · class 与 self、复杂度自测

**知识点**：`class Solution: def f(self, ...)` 结构、`self.lcp()` 调用带 self、**def 缩进层级 = 作用域**（014 翻车点）；复杂度口算抽查。

| 题 | 通关标准 | 自测用例 |
|---|---|---|
| **704 二分查找（手写）** | **while left <= right**（带等号）；mid 用 `left + (right-left)//2` 防「习惯写 (l+r)/2 越界」的问题在 Python 不存在但要会讲；返回 -1 | `[-1,0,3,5,9,12]` 找 9→4、找 2→-1、`[5]` 找 5→0 |
| **350 两个数组的交集 II** | 保留**重复次数**的交集（与 349 之差！）——Counter 取 min 或删减法 | `[1,2,2,1]`+[2,2]→[2,2]、`[4,9,5]`+[9,4,9,8,4]→[4,9] |

**常见坑**：350 和 349 只有「去不去重」一个词的差别——审题 5 分钟里必须写出「保留重复几次」这句；704 的 `<=` 少等号会漏掉单元素区间。

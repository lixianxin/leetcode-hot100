## 第 2 块 · 09:25–10:05 001 两数之和（40 分钟，六步）

- [ ] **2.1 读题（5 min，纸上）**：在纸上写四行——
  - 输入：数组 `nums`、目标 `target`
  - 输出：两个**下标**（不是值！）
  - 约束：同一个元素不能用两次；恰好一个解
- [ ] **2.2 想暴力（7 min，纸上）**：写出思路一句话：「把每一对 (i, j) 都试一遍，看 nums[i] + nums[j] == target」。再手推一遍示例 `[2,7,11,15], 9`：2+7=9 ✓ 返回 [0,1]。
- [ ] **2.3 编码（15 min，键盘，一次写完）**：

  ```python
  class Solution:
      def twoSum(self, nums, target):
          n = len(nums)
          for i in range(n):
              for j in range(i + 1, n):
                  if nums[i] + nums[j] == target:
                      return [i, j]
  ```

  写之前想清楚一件事（想清楚再敲）：**内层 j 为什么从 `i + 1` 开始？**
  因为 j < i 的组合外层早就试过了，而且 `j = i` 会自己加自己——这就是「同一元素不能用两次」在代码里的样子。

- [ ] **2.4 自测（5 min，只换用例不提交）**：用「运行」跑这 4 个：
  - `[2,7,11,15], 9` → `[0,1]`
  - `[3,3], 6` → `[0,1]`（重复值，防自己配自己）
  - `[3,2,4], 6` → `[1,2]`（防返回成 [0,0]）
  - `[-3,4,3,90], 0` → `[0,2]`（负数）

  - 输出：True / False
  - 约束：**负数一律不是回文**（-121 反过来是 121-）；个位数都是回文
- [ ] **3.2 想思路（7 min，纸上）**：一句话：「把 x 转成字符串，和它自己的倒序比」。手推：121 → "121"，倒序 "121"，相等 ✓；-121 → "-121"，倒序 "121-"，不等 ✓。
- [ ] **3.3 编码（15 min）**：

  ```python
  class Solution:
      def isPalindrome(self, x):
          if x < 0:
              return False
          s = str(x)
          return s == s[::-1]
  ```

  注意第一行 `if x < 0` 不能省——不写它，-121 会返回 False 碰巧过示例，但那是「碰巧对」，不是「想对了」。
- [ ] **3.4 自测（5 min）**：`121`→true，`-121`→false，`10`→false（"10" vs "01"），`0`→true。

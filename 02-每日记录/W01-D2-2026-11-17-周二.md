## 第 3 块 · 09:15–09:55 题 26 删除有序数组中的重复项（40 分钟，六步）

- [ ] **3.1 读题（5 min，纸上）**：数组已排序、原地去重、**返回长度 k**、`nums` 前 k 个要是去重结果。
  注意坑：返回的是 k 不是数组；也不能只写 `return len(set(nums))`（长度对但数组没被改）。
- [ ] **3.2 想思路（7 min，纸上）**：手推 `[1,1,2]`——
  - 因为**已排序**，重复的都挨在一起
  - 一个"写指针" k（下一个不重复的数该放的位置），一个"读指针" i 往右扫
  - 读到的数 ≠ `nums[k-1]`（即和上一个留下的数不同）→ 写到 `nums[k]`，k += 1
- [ ] **3.3 编码（15 min，一次写完）**：
  ```python
  class Solution:
      def removeDuplicates(self, nums):
          k = 1
          for i in range(1, len(nums)):
              if nums[i] != nums[k - 1]:
                  nums[k] = nums[i]
                  k += 1
          return k
  ```
  编码前想清楚两个为什么：k 为什么从 1 开始？（第一个数永远留下）；i 为什么从 1 开始？（同上）
- [ ] **3.4 自测（8 min）**：
  - `[1,1,2]` → 返回 2，且 nums 前 2 个是 `[1,2]`
  - `[0,0,1,1,1,2,2,3,3,4]` → 返回 5
  - `[1]` → 返回 1（单元素）
  - `[1,1,1]` → 返回 1（全相同）

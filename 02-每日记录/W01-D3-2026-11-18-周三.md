## 第 2 块 · 08:55–09:35 题 66 加一（40 分钟，六步）

- [ ] **2.1 读题（5 min，纸上）**：数组表示一个非负整数（`[1,2,3]` 就是 123），给它加 1，**返回新数组**。
  边界：全 9 要进位（`[9,9]` → `[1,0,0]`）；单个 0（`[0]` → `[1]`）。
- [ ] **2.2 想思路（7 min，纸上）**：为什么必须**从后往前**？
  因为加 1 是作用在个位（末尾）上的，只有进位才往左走。手推 `[9,9]`：
  - 末位 9 → 变 0，继续往前
  - 前一位 9 → 变 0，继续往前
  - 走完了还都是 9 → 头部插 1
- [ ] **2.3 编码（15 min，一次写完）**：
  ```python
  class Solution:
      def plusOne(self, digits):
          for i in range(len(digits) - 1, -1, -1):
              if digits[i] != 9:
                  digits[i] += 1
                  return digits          # 不进位，直接结束
              digits[i] = 0              # 是 9 就变 0，继续往前
          digits.insert(0, 1)            # 全 9，头部补 1
          return digits
  ```
  三个要想清楚的点：①`range` 三个参数各是什么；②为什么 `return` 写在循环**里面**是对的（一旦不进位就该收工）；③`insert(0, 1)` 是 O(n) 操作，为什么这题可以接受。
- [ ] **⚠️ 硬规矩**：禁止 `int("".join(map(str, digits))) + 1` 再转回来。能过题，但你什么都学不到，面试会被追问「不转整数怎么办」。
- [ ] **2.4 自测（8 min）**：`[1,2,3]`→`[1,2,4]`；`[9,9]`→`[1,0,0]`；`[0]`→`[1]`；`[9]`→`[1,0]`（这一条最容易漏，全 9 只有一位）

## 第 3 块 · 09:45–10:25 题 58 最后一个单词的长度（40 分钟）

- [ ] **3.1 读题（5 min，纸上）**：给一个字符串（可能首尾有空格、单词间多个空格），返回**最后一个单词**的长度。
  边界：`"a"` → 1；全是空格？题目保证至少有一个单词。
- [ ] **3.2 想思路（7 min，纸上）**：两条路，都写下来再选：
  - 路线 A：`s.split()` 得到单词列表 → 取 `words[-1]` → `len(...)`
  - 路线 B：从末尾开始往回扫，跳过尾部空格，再数到下一个空格
  **先用 A 写对**（3 行），有余力再试 B。
- [ ] **3.3 编码（15 min）**：
  ```python
  class Solution:
      def lengthOfLastWord(self, s):
          words = s.split()          # 不带参数！自动处理多个连续空格和首尾空格
          return len(words[-1])
  ```
- [ ] **3.4 自测（8 min）**：
  - `"Hello World"` → 5
  - `"   fly me   to   the moon  "` → 4（考点：尾部有空格、中间多空格）
  - `"a"` → 1
  - `"day"` → 3（只有一个单词，没有空格）
  如果你的代码在这条挂了，检查是不是写了 `split(" ")`。

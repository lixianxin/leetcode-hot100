## 第 3 块 · 09:30–10:10 题 014 最长公共前缀（40 min，六步）

- [ ] **3.1 读题（5 min，纸上）**：字符串数组，返回**所有串的最长公共前缀**；没有公共前缀返回 `""`。
  边界：数组只有 1 个串 → 前缀是它自己；空串混在里面 → 返回 `""`。
- [ ] **3.2 想思路（7 min，纸上）**：两条路线：
  - 路线 A（纵向）：一个字符一个字符地比——第 0 位所有串都相同？第 1 位呢？…… **关键防御：比到某个串自己的长度尽头就停，否则 IndexError**
  - 路线 B（横向）：拿第 1 个串当前缀，逐个和后面的串"对齐收缩"
  选一条写伪码。
- [ ] **3.3 编码（15 min，一次写完）**。纵向版骨架（卡住才看，先自己写）：
  ```python
  if not strs:
      return ""
  first = strs[0]
  for i in range(len(first)):
      ch = first[i]
      for s in strs[1:]:
          if i >= len(s) or s[i] != ch:   # ← 这条 or 是防越界的命根子
              return first[:i]
  return first
  ```
- [ ] **3.4 自测（8 min）**：`["flower","flow","flight"]`→`"fl"`；`["dog","racecar","car"]`→`""`；`["a"]`→`"a"`；`["ab","a"]`→`"a"`（这条专打越界）

## 第 4 块 · 10:20–11:00 题 013 罗马数字转整数（40 min，六步）

- [ ] **4.1 读题（5 min，纸上）**：七种符号 I/V/X/L/C/D/M = 1/5/10/50/100/500/1000；**小的在大的前面 → 减**（IV=4，IX=9）。写出手推：`MCMXCIV` = 1000 - 100 + 1000 - 10 + 100 - 1 + 5 = 1994。
- [ ] **4.2 想思路（7 min，纸上）**：从左往右扫，每一位只看它和**下一位**：
  - `s[i] < s[i+1]` → 减去 `s[i]`
  - 否则 → 加上 `s[i]`
  **坑在哪：最后一位没有"下一位"，单独处理——这正是预警清单里"比较下一位时越界"那条**
- [ ] **4.3 编码（15 min，一次写完）**：
  ```python
  vals = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
  total = 0
  for i in range(len(s)):
      if i + 1 < len(s) and vals[s[i]] < vals[s[i + 1]]:
          total -= vals[s[i]]
      else:
          total += vals[s[i]]
  return total
  ```
  两个要想清楚：①为什么 `i + 1 < len(s)` 必须写在**条件的前半**（先判越界再取值）；②为什么减的永远是"当前位"不是"下一位"。
- [ ] **4.4 自测（8 min）**：`"III"`→3；`"IV"`→4；`"IX"`→9；`"LVIII"`→58；`"MCMXCIV"`→1994

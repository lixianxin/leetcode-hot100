### 题目（LeetCode 80）

给你一个有序数组 `nums`，请你**原地**删除重复出现的元素，使得出现次数超过两次的元素**只出现两次**，返回删除后数组的新长度。

不要使用额外的数组空间，你必须在**原地修改输入数组**并在使用 **O(1)** 额外空间的条件下完成。

**示例 1**

```
输入：nums = [1,1,1,2,2,3]
输出：5, nums = [1,1,2,2,3,_]
解释：函数应返回新长度 5，并且原数组前 5 个元素被修改为 1,1,2,2,3
```

**示例 2**

```
输入：nums = [0,0,1,1,1,1,2,3,3]
输出：7, nums = [0,0,1,1,2,3,3,_]
```

**约束**：`1 <= nums.length <= 3*10^4`；`-10^4 <= nums[i] <= 10^4`；`nums` 已按**非严格递增**排列。

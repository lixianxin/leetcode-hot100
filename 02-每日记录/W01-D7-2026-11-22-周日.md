## 第 1 块 · 08:30–09:10 题 014 最长公共前缀 · 重做（40 min，六步）

- [ ] **① 读题（5 min，纸上）**：输入字符串数组，输出所有串的最长公共前缀；没有公共前缀返回 `""`。
  边界四条先列：数组只有 1 个串 / 空串混在里面 / 某串比基准短（防越界）/ 全部相同。
- [ ] **② 想思路（7 min，纸上）**：纵向扫描——拿第一个串当基准，逐位 i 比所有串的第 i 个字符；**发现不相等或某串长度不够就停，返回 `first[:i]`**。
  ⚠️ 上次的模型错因：set 交集——set 无序，前缀按位置，**顺序敏感的问题禁用 set**。
- [ ] **③ 编码（13 min，本地空白文件一次写完，不边写边调）**。卡住才看骨架：
  ```python
  if not strs:
      return ""
  first = strs[0]
  for i in range(len(first)):
      ch = first[i]
      for s in strs[1:]:
          if i >= len(s) or s[i] != ch:   # ← 防越界的 or 是命根子
              return first[:i]
  return first
  ```
- [ ] **④ 自测（8 min）**：`["flower","flow","flight"]`→`"fl"`；`["dog","racecar","car"]`→`""`；`["a"]`→`"a"`；`["ab","a"]`→`"a"`（专打越界）

## 第 2 块 · 09:20–10:00 题 013 罗马数字转整数 · 重做（40 min，六步）

- [ ] **① 读题（5 min，纸上）**：七种符号 I/V/X/L/C/D/M = 1/5/10/50/100/500/1000；**小的在大的前面 → 减**（IV = -1+5 = 4）。
  手推：`MCMXCIV` = 1000 − 100 + 1000 − 10 + 100 − 1 + 5 = 1994。
- [ ] **② 想思路（7 min，纸上）**：从左往右扫，每位只看它和**下一位**：`s[i] < s[i+1]` → 减 `s[i]`；否则加 `s[i]`。
  ⚠️ 上次的错因：**越界前置没落码**——最后一位没有"下一位"，`i + 1 < len(s)` 必须写在条件**前半**，先判越界再取值。
- [ ] **③ 编码（13 min，本地空白文件一次写完）**。卡住才看骨架：
  ```python
  vals = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
  total = 0
  for i in range(len(s)):
      if i + 1 < len(s) and vals[s[i]] < vals[s[i + 1]]:
          total -= vals[s[i]]        # 减的是当前位，不是下一位
      else:
          total += vals[s[i]]
  return total
  ```
- [ ] **④ 自测（8 min）**：`"III"`→3；`"IV"`→4；`"IX"`→9；`"LVIII"`→58；`"MCMXCIV"`→1994
- [ ] **⑤ 贴 LeetCode 提交验证（3 min）**　**⑥ 复盘（4 min）**：口述——「为什么减的是当前位不是下一位？`i+1 < len(s)` 写在后半会炸在哪？」
- 结果：☐ 独立一遍过 ☐ 提示后过 ☐ 没过，卡在___

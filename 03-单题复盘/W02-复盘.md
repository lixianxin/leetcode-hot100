### 268. 丢失的数字 · 简单 · 首次 11/24

- **模型**：缺一个数 = 完整集合 − 现有集合。完整集合 `set(range(len(nums)+1))`——**n 是 len(nums)**，因为少了一个数后数组长度恰为 n；完整值域 [0, n] 共 n+1 个。
- **卡点**：range 右边界想了一下（+1 是因为 range 左闭右开，要包含 n）；`new_set[0]` 报越界的风险也和这个边界同源。
- **模板**：`(set(range(len(nums)+1)) - set(nums)).pop()`——更精简版（pop() 直接取差集唯一元素；此时不用转 list）。
- **标记**：☑ 独立（13 min）｜ 裸写：☐（10:45 块）
- **版②了解**：①公式解 `n(n+1)//2 - sum(nums)`（O(1) 空间，W03 哈希周对比学）；②**原地标记 O(1) 空间**解（见 448 条目）。
- **重做**：☐ 11/27 ／ ☐ 12/01

### 448. 找到所有数组中消失的数字 · 简单 · 首次 11/24

- **模型**：同 268，值域 [1, n]（比 268 差一位），完整集合 `set(range(1, len(nums)+1))`，差集后转列表。
- **卡点**：无实质卡点。主动暴露盲区：「没想出 O(1) 空间 O(n) 时间的写法」——诚实且正确的观察。
- **模板**：`sorted(set(range(1, len(nums)+1)) - set(nums))`。
- **标记**：☑ 独立 ｜ 裸写：☐（10:45 块）
- **版②了解（重要）——原地哈希 / 原地标记**：不开任何新集合，把「值 v 出现过没」的信息**记到下标 v-1 的正负号里**：

  ```python
  # 思路：值 v 出现 → 把 nums[|v|-1] 变负（负号 = 「值 |v| 出现过」的标记）
  for v in nums:
      if nums[abs(v) - 1] > 0:
          nums[abs(v) - 1] = -nums[abs(v) - 1]
  return [i + 1 for i, x in enumerate(nums) if x > 0]  # 还是正的 = 没人标记过 = 缺失
  ```

  这套「**用元素自身当标记存储**」的思路叫原地哈希，是 Hot 100 第 41 题（缺失的第一个正数）和矩阵专题（73 置零）的正式技巧。**今天不用学，W05 原地技巧周会正面教**——你今天能意识到「有更好的空间方案」，这个敏感度本身就是收获。
- **重做**：☐ 11/27 ／ ☐ 12/01

### 268. 丢失的数字 · 简单 · 首次 11/24

- **模型**：缺一个数 = 完整集合 − 现有集合。完整集合 `set(range(len(nums)+1))`——**n 是 len(nums)**，因为少了一个数后数组长度恰为 n；完整值域 [0, n] 共 n+1 个。

### 448. 找到所有数组中消失的数字 · 简单 · 首次 11/24

- **模型**：同 268，值域 [1, n]（比 268 差一位），完整集合 `set(range(1, len(nums)+1))`，差集后转列表。
- **卡点**：无实质卡点。主动暴露盲区：「没想出 O(1) 空间 O(n) 时间的写法」——诚实且正确的观察。
- **模板**：`sorted(set(range(1, len(nums)+1)) - set(nums))`。
- **标记**：☑ 独立 ｜ 裸写：☑ 10:02 set+sorted 版一次写出
- **版②了解（重要）——原地哈希 / 原地标记**：不开任何新集合，把「值 v 出现过没」的信息**记到下标 v-1 的正负号里**：

  ```python
  # 思路：值 v 出现 → 把 nums[|v|-1] 变负（负号 = 「值 |v| 出现过」的标记）
  for v in nums:
      if nums[abs(v) - 1] > 0:
          nums[abs(v) - 1] = -nums[abs(v) - 1]
  return [i + 1 for i, x in enumerate(nums) if x > 0]  # 还是正的 = 没人标记过 = 缺失
  ```

  这套「**用元素自身当标记存储**」的思路叫原地哈希，是 Hot 100 第 41 题（缺失的第一个正数）和矩阵专题（73 置零）的正式技巧。正式教学在 **W05 原地技巧周**。
- **版②原地哈希·提前试写记录（10:02，超前进度，△ 提示后过）**：照复盘骨架自己写，一次自查出 2 个 bug：
  1. **漏 `abs()`**：`index = nums[i] - 1` 没包 abs——前面已被标记成负数时 index 变 -1。**Python 负下标不报错、回绕到数组末尾**，标记错格子还查不出来（静默 bug，比崩溃更危险）。
  2. **判断对象混淆**：`if nums[index] > 0` 判断的是**该位置的值**（还是正的 = 没人标记过 = 才取负做标记），不是下标 index 本身是否大于 0。
  - **教训一句话**：原地标记取下标必须 `abs()` 包住；负下标在 Python 里合法，靠报错抓不到这类 bug，只能靠「想清楚 index 语义」。
  - 附带答疑：输入/输出数组**不计入**空间复杂度（LeetCode 惯例：输出不算额外空间），所以可以新建 res 返回列表。
- **重做**：☐ 11/27 ／ ☐ 12/01

### 88. 合并两个有序数组 · 简单 · 首次 11/25

- **模型**：**指定模型 = 原地从后往前填**（p1=m-1、p2=n-1、p=m+n-1，取大者填 p）——**本次未做**，写的是「拷贝 nums2 到 nums1 尾部 + sort()」。
- **版本①（已提交，1 min）**：for 拷贝 + `nums1.sort()`。能过但有两个问题：①**索引写错了**：`nums2[i - m - 1]`，i=m 时取 `nums2[-1]`（末元素），整段是轮换拷贝——**碰巧 multiset 不变、被 sort() 掩盖**，正确应为 `i - m`；②sort 是 O((m+n)log(m+n))，指定模型 O(m+n)。
- **卡点**：`range(m+1, ...)` 起点想错一次（自纠为 m）；补做版卡 `p1 < 0` 越界一次（自加 `p1 >= 0` 先判再取）
- **模板（指定模型版，10:02 补做通过）**：

  ```python
  p1, p2, p = m - 1, n - 1, m + n - 1
  while p2 >= 0:                      # nums2 填完即收工；p1 有剩的本来就在家
      if p1 >= 0 and nums1[p1] >= nums2[p2]:
          nums1[p] = nums1[p1]; p1 -= 1
      else:
          nums1[p] = nums2[p2]; p2 -= 1
      p -= 1
  ```

  （用户版 `>`/`==` 两分支相同，可合并为 `>=`；`p -= 1` 放 if 外只写一次——正确习惯，保持）
- **模板一句话**：三个指针各司其职（p1/p2 读、p 写），先判边界再取值，大者填 p、同退。
- **标记**：版本① ☑ 独立（1 min，索引 bug 被 sort 掩盖）｜指定模型版 ☑ 提示后过（骨架小算给、代码自写）｜**裸写：☑ 10:25 关提示一次过**（主动用 `>=` 合并分支写成优化版，无越界卡点）
- **重做**：☐ 11/28 ／ ☐ 12/02

### 977. 有序数组的平方 · 简单 · 首次 11/25

- **模型**：**指定模型 = 双指针两头收**（原数组非递减 → 平方后的最大值只出现在两端；左右指针比绝对值，大者填结果尾部，从后往前填）——**本次未做**，写的是「原地平方 + sorted()」。
- **版本①（已提交）**：`for` 平方 + `sorted(nums)`，O(n log n)。**任务卡明写「不许 sorted 一行过，必须双指针版」——本条按违反指定模型记录**，sort 版不算通过本题的学习目标。
- **知识点问答**：平方函数 = `x ** 2` 或 `x * x`；`math.sqrt` 是**开根号**（用户答对了），且负数输入直接 ValueError——本题有负数，sqrt 方向就是错的。
- **模板（双指针两头收版，10:02 补做通过）**：

  ```python
  i, j = 0, len(nums) - 1
  index = j
  res = [0] * len(nums)
  while i <= j:
      if abs(nums[i]) > abs(nums[j]):
          res[index] = nums[i] ** 2; i += 1
      else:
          res[index] = nums[j] ** 2; j -= 1
      index -= 1
  return res
  ```

  （用户版相等分支取 i 退 j——正确：相等时任取一个，结果集合不变）
- **模板一句话**：平方最大值只出现在两端；比绝对值，大者填 res 尾部、从后往前填。
- **标记**：版本① ☑ 独立但违反指定模型 ｜双指针版 ☑ 提示后过（骨架小算给、代码自写；卡 res 越界一次自纠）｜**裸写：☑ 10:25 关提示一次过**（用 `>=` 合并相等分支写成优化版，无越界卡点）
- **重做**：☐ 11/28 ／ ☐ 12/02

### 344. 反转字符串 · 简单 · 首次 11/26

- **模型**：原地双指针两头交换。i 从头、j 从尾，`s[i], s[j] = s[j], s[i]`，i 走一步 j 退一步，`i >= j` 停。
- **卡点**：无。纸上边界理解到位——「奇数中间那个不用换，偶数换的是相邻中间 2 个；`len(s)//2` 就是**需要交换的次数**」。这句答得准：`range(len(s)//2)` 的循环次数 = 交换对数，不是「换到第几个下标」。
- **模板**：

  ```python
  j = len(s) - 1
  for i in range(len(s) // 2):
      s[i], s[j] = s[j], s[i]
      j -= 1
  ```

- **重要区分（别矫枉过正）**：这里 i、j 是**两个反向指针**（一个头一个尾），职责不同、方向相反，是必要结构；和 027 的 i/f 冗余（同向、干同一件事）不是一回事。判断标准：**两个变量方向相反 = 双指针；方向相同且同步自增 = 冗余**。
- **复杂度**：时间 O(n)（n/2 次交换），额外空间 O(1)（原地，题面要求返回 None）。
- **标记**：☑ 独立 ｜ **裸写：☑ 10:01 关提示一次过**（与首写版一致，无卡点）

### 125. 验证回文串 · 简单 · 首次 11/26

- **模型**：先过滤成干净串（逐字符 `isalnum` + `lower` + join），再对干净串两头往中间比。
- **卡点（有价值，回扣早上考点）**：一开始写成 `s.lower().isalnum()`——这是**对整串做「是否全为字母数字」的判定，返回单个 bool**；`"a1!b".isalnum()` 因为 `!` 得 False，而且它根本没有「过滤」动作。自己想通后改为逐字符 `for ch in s if ch.isalnum()`。
  - **一句话教训**：`isalnum()` 的作用域是**单个字符**；想过滤就得逐个遍历，整串调用只会得到一个 bool。早上自检答的「留下 a1b」正是逐字符过滤的结果——概念懂，落码时把「整体判定」和「逐字符过滤」两个用法混了。
- **模板**：

  ```python
  s = "".join(ch.lower() for ch in s if ch.isalnum())
  j = len(s) - 1
  for i in range(len(s) // 2):
      if s[i] != s[j]:
          return False
      j -= 1
  return True
  ```

- **正确性要点**：`""`（全符号输入）→ 干净串为空 → `range(0)` 不进循环 → 直接 True，**符合题面「空串算回文」，不需要也不许特判**。`"0P"` → `"0p"` → `0 != p` → False（用 isalnum 保住了数字，避开了清单埋的 isalpha 坑）。
- **复杂度**：时间 O(n)；空间 **O(n)**——干净串是新建的。存在 O(1) 空间写法（原串上两头指针、跳过非 alnum、比较时 lower），属进阶版，**今天不写**，W05 原地技巧周再碰。
- **标记**：☑ 独立（过滤写法卡一次，自纠，未看提示/题解）｜ **裸写：☑ 10:01 关提示一次过**（与首写版一致，无卡点）
- **重做**：☐ 11/29 ／ ☐ 12/03

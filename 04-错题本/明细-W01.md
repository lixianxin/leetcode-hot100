## 格式示例（虚构，用来给你看长什么样，不是你的记录）

### 001. 两数之和 · 简单 · W01-D1（示例）

**我的错误代码**

```python
seen = {}
for i, x in enumerate(nums):
    seen[x] = i                  # ← 错在这里：先把当前元素存进去
    if target - x in seen:
        return [i, seen[target - x]]
```

**错在哪**

第 3 行写入，第 4 行才查询。对 `nums = [3,3], target = 6`：
- `i=0`：先把 `3` 存进 `seen`，紧接着查 `need = 3`，命中的是**自己**刚存的那条，返回 `[0,0]`
- 同一元素被用了两次，违反题面"同一元素不能重复使用"

**正确写法**

```python
seen = {}
for i, x in enumerate(nums):
    need = target - x
    if need in seen:             # ← 先查
        return [seen[need], i]
    seen[x] = i                  # ← 后存
```

**为什么**

查询和写入的**顺序**不是风格问题，是被"元素不能重复使用"这个约束逼出来的。先存 = 允许自己和自己配对；先查 = 只允许和之前出现过的数配对。

**一句话教训**

凡是"不能重复使用同一元素"的题，都要检查**查询与写入的先后**；写完示例用例过了不代表对，要专门造一个"重复值"用例去打它。

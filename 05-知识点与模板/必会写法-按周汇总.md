### 001 两数之和 · 两版

| 版本 | 要求 | 状态 |
|---|---|---|
| 暴力双循环 | **版① 必会**（D1 已过） | ☑ |
| 哈希一次遍历 | 版①′（W03 哈希周验收） | 预习中 |

```python
# 版① 暴力（必会）
for i in range(len(nums)):
    for j in range(i + 1, len(nums)):   # j 从 i+1 起：自己不和自己配对
        if nums[i] + nums[j] == target:
            return [i, j]

# 版①′ 哈希（W03 验收，口述点：先查后存）
seen = {}
for i, x in enumerate(nums):
    if target - x in seen:              # 先查
        return [seen[target - x], i]
    seen[x] = i                         # 后存——反了 [3,3],6 会 [0,0]
```

### 009 回文数 · 两版（已攻克，11/23 起免重做）

| 版本 | 要求 | 状态 |
|---|---|---|
| 字符串 3 行 | 版① 必会（最短） | ☑ |
| 半翻转 | 版①′ 必会（面试常问「防溢出」） | ☑ |

```python
# 版① 字符串
if x < 0:
    return False
s = str(x)
return s == s[::-1]

# 版①′ 半翻转（口述点：x%10==0 那条不能删，否则 10 → True）
if x < 0 or (x % 10 == 0 and x != 0):
    return False
rev = 0
while x > rev:
    rev = rev * 10 + x % 10   # % 取末位拼到 rev
    x //= 10                  # // 删末位
return x == rev or x == rev // 10   # 偶长度 / 奇长度（中间位不看）
```

s = 0
for f in range(1, len(nums)):
    if nums[f] != nums[s]:

### 066 加一 · 版① 单循环（**必会，版② 只了解**）

```python
# 版①（必会）：边走边把 9 置 0，无内层循环
# return 缩进 = 收工时机：非 9 加完立刻收工（if 内）；全 9 走完补 1 收工（循环外）
for i in range(len(digits) - 1, -1, -1):
    if digits[i] != 9:
        digits[i] += 1
        return digits
    digits[i] = 0
digits.insert(0, 1)
return digits

# 版②（了解）：遇非 9 回头清零，多一个内层循环，逻辑等价
```

### 014 最长公共前缀 · 版① 纵向扫描（11/22 重做）

```python
# 口述点：①前缀按位置相等，禁用 set（无序）；②i >= len(s) 防越界，写在取值前面
first = strs[0]
for i in range(len(first)):
    ch = first[i]
    for s in strs[1:]:
        if i >= len(s) or s[i] != ch:   # or 的左半先判长度再取字符
            return first[:i]            # 有任何一位不等 → 公共前缀到 i 为止
    # 内层全通过（这一位所有串都相同）→ 什么都不做，继续下一位
return first                            # ← 在 for i 外面：每一位全通过，整个串都是公共前缀
```

### 013 罗马数字转整数 · 一版（11/22 重做）

```python
# 口述点：小的在大的前面 → 减当前位；越界判断 i+1 < len(s) 写在条件前半
vals = {'I': 1, 'V': 5, 'X': 10, 'L': 50, 'C': 100, 'D': 500, 'M': 1000}
total = 0
for i in range(len(s)):
    if i + 1 < len(s) and vals[s[i]] < vals[s[i + 1]]:
        total -= vals[s[i]]
    else:
        total += vals[s[i]]
return total
```

## W01 通用写法规则（5 条，全部来自真实踩坑）

| 规则 | 来源 |
|---|---|
| 刷题默认正下标（`range(len-1, -1, -1)`），负下标只用于取尾（`a[-1]`）和切片 | 066 负下标混乱 |
| 倒序 range 三参数缺一不可，右边界是 **-1**（想包含下标 0），含左不含右对倒序同样成立 | 066 最高位漏 |
| `return` 的缩进 = 收工时机。先在纸上列「有几种收工时机」，再定缩进 | 066、014 |
| 判断容器为空用 `if not data`；`is None` 只用于变量可能真的是 None | 058 |
| 要求「顺序 / 位置」的问题禁用 set——set 只回答「在不在」，不回答「第几个」 | 014 set 交集 |
| 边界清单在**读题 5 分钟**时列在纸上（空 / 单元素 / 无解 / 更短），编码时逐条勾 | 013、014 |

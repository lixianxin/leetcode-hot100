# 代码骨架模板库

> 用途：可复用的最小代码骨架。做题时先找模板，别从零想。
> 关联：知识点-WNN-*.md、示范题-NNN-*.md
> 更新：2026-11-14（W01 建版，随专题推进逐步补充）

---

## 使用规则

1. **模板是骨架，不是答案。** 套用前先确认适用条件，条件不符不能用。
2. **每个模板必须记住三件事**：什么特征触发它、核心代码长什么样、什么情况下会失效。
3. **模板抄错比不会更危险**（比如二分左右边界混用），所以每个模板只保留**一个**写法，不提供多种变体。

## 模板 01 · 边界自测清单（每题必用）

**触发**：所有题，提交前最后一步。

**骨架**

| 类别 | 要造什么 | 常见坑 |
|---|---|---|
| 空输入 | `[]`、`""`、`None`（如允许） | 直接取 `a[0]` 会炸 |
| 单元素 | `[1]`、`"a"` | 循环范围算成 0 次 |
| 重复值 | 全部相同 `[3,3,3]` | 去重/配对逻辑出错 |
| 极值/负数 | 最大最小、负数、0 | 溢出、符号、边界收缩方向 |
| 无解 | 题目允许无解时 | 忘了兜底 `return` |

**为什么有效**：题目给的示例永远是"正常情况"，边界才暴露原理漏洞。**只过示例就提交，是新手最常见的自欺。**

## 模板 02 · 读写双指针（原地修改数组）

**触发**：题目要求**原地**删除/移动/压缩数组，且要保留相对顺序。例：26 去重、27 移除元素、283 移动零。

**骨架**

```python
k = 0                      # 写指针：下一个"要保留的元素"放哪
for i in range(len(nums)): # 读指针 i：从头扫到尾
    if 保留nums[i]的条件:   # 例如 nums[i] != nums[k-1]
        nums[k] = nums[i]  # 写到 k 位置
        k += 1             # 写指针前移
return k                   # 返回有效长度（不是数组！）
```

**三个变体怎么写**

| 题目 | 「保留条件」写什么 | 返回什么 |
|---|---|---|
| 26 去重 | `k == 0 or nums[i] != nums[k-1]` | k |
| 27 移除元素 | `nums[i] != val` | k |
| 283 移动零 | 分两段：非零的往前写，剩下的补 0 | 无（原地改） |

**失效条件**：要求保持"删除后元素顺序"以外的顺序，或需要返回删除的元素本身，这个模板不适用。

## 模板 03 · 计数哈希（查重 / 判异位词）

**触发**：需要判断"某个东西出现过没"或"两个集合元素是否完全相同"。例：1 两数之和、217 存在重复、242 异位词。

**骨架 A：边查边存（最常用）**

```python
seen = {}                       # 值 → 下标 / 值 → 出现次数
for i, x in enumerate(nums):
    if 需要的东西 in seen:       # 先查
        return 结果
    seen[x] = i                 # 后存（顺序不能反，见 001 错题示例）
```

**骨架 B：直接比集合**

```python
return len(set(nums)) != len(nums)        # 217 判重复
return sorted(s) == sorted(t)             # 242 判异位词（最简单版本）
```

**失效条件**：
- 需要保留"第一次出现的位置"时，A 里的 `seen[x] = i` 不能覆盖已有值
- 元素不可哈希（如 list、dict）不能放进 set/dict

## 模板 04 · 双重循环暴力枚举（基线解法）

**触发**：任何题的第一步。**先有暴力解，才有优化方向。**

**骨架**

```python
for i in range(n):
    for j in range(i + 1, n):   # ← i+1 而不是 i，否则同一元素会被用两次
        if 条件(nums[i], nums[j]):
            return 结果
```

**复杂度**：O(n²)。**用途**：作为正确性基线，用小数据对拍优化解。

**新手最容易错的地方**：内层写成 `range(i, n)`，导致自己和自己配对。001 两数之和、015 三数之和、005 最长回文都会在这里翻车。

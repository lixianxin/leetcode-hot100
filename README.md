## 学习方法：单题六步（每题 50 分钟）

顺序是「**先想清原理，再敲代码**」，不是「写完再搞懂」。

| 步骤 | 时间 | 产出 |
|---|---|---|
| ① 读题 | 5 min | 纸上写清输入、输出、边界、约束 |
| ② 想暴力解 | 7 min | 纸上写出暴力解，手推一个小例子跑通 |
| ③ 找瓶颈 | 8 min | 一句话说出「哪个动作被重复做了 n 次」 |
| ④ 编码 | 15 min | 一次写完，不边写边调 |
| ⑤ 自测 | 5 min | 空 / 单元素 / 重复 / 极值 四类用例 |
| ⑥ 复盘 | 10 min | 模型、卡点、模板、标记 |

**核心判据**：不写代码，能不能用嘴讲清「这题怎么做、为什么这样做对」。讲不清就不敲键盘。

完整示范见 [05-知识点与模板/示范题-001-两数之和.md](05-知识点与模板/示范题-001-两数之和.md)

## 三条铁律

1. **裸写不通过 = 没学会。** 不看笔记能写出并过全部用例，才算这题完成。
2. **错题必须保留错误代码。** 只记正确答案的错题本没有诊断价值——错误的形状比正确的形状更有信息量。
3. **按完成度推进，不按日期推进。** 某周少来一天，就整周顺延，不压缩内容。

## 关于这份记录的诚实说明

- 刷完 Hot 100 是达到大厂算法面试的入场水平，不是「算法大牛」。
- 每道题的掌握程度按实际标记：独立做出 / 看了提示 / 抄了题解。**抄的不会被标成独立的**，这个仓库的价值就在于标记是真实的。
- 计划周期按每周 5 天 × 3 小时估算为 14 周，实际会因状态波动顺延。
